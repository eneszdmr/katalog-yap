# Katalog web modülü

Bu paket, paylaştığınız MariaDB DDL'sindeki mevcut `businesses`, `catalogues`, `products`, `orders` ve `visits` tablolarını kullanır. Var olan verileri taşımaz veya tabloları yeniden oluşturmaz. Ziyaretçi sayısının hızlı hesaplanması için yalnızca küçük `catalog_live_sessions` tablosunu ekler.

## Hosting'e yükleme

1. `database/migration_live_catalog.sql` dosyasını mevcut veritabanında bir kez çalıştırın. Diğer DDL dosyalarınızı tekrar çalıştırmayın.
2. `config.example.php` dosyasını `config.local.php` olarak kopyalayın. MariaDB veritabanı, kullanıcı ve parolayı girin. Bu ayar dosyası `public/` klasörünün dışında kalmalıdır.
3. `public/` klasörünün **içindeki dosyaları** domainin web köküne (çoğu hostingte `public_html`) yükleyin. `config.local.php` dosyasını web kökünün bir üst klasörüne koyun. Hostinginiz document root değiştirebiliyorsa `public/` klasörünü doğrudan document root yapabilirsiniz.
4. Hostingte PHP 8.1+, PDO MySQL ve HTTPS etkin olmalı.
5. Katalog bağlantısı: `https://alanadiniz.com/?c=KATALOG_SLUG` (slug yerine katalog ID'si de kullanılabilir).

## Mevcut veritabanına uyarlama

- Ürünler `products` tablosundan `catalog_id` ile okunur.
- Kataloglar `catalogues` tablosunda `slug` veya `id` ile bulunur; `is_active=1` olmalıdır.
- Firma adı, WhatsApp numarası, para birimi, tema rengi, asgari sipariş ve kargo ücreti `businesses` tablosundan alınır.
- Siparişler uygulamanızın kullandığı `orders` tablosuna `NEW` durumuyla yazılır. `items_json`, `timeline_json` ve `payload_json` doldurulur; `catalogues.order_count` artırılır. Stok otomatik düşürülmez (`stock_deducted=0`).
- Aktivite `visits` tablosuna yazılır: `catalog_open`, `add_to_cart`, `product_view`. Ziyaretçi sayısı son 90 saniyede heartbeat gönderen tarayıcı oturumlarının sayısıdır.

## Uçlar

- `GET /api.php?action=catalog&key=SLUG`: katalog, ürünler ve anlık ziyaretçi sayısı.
- `POST /api.php?action=activity`: JSON `{ "key":"SLUG", "session_id":"...", "event":"heartbeat|catalog_open|product_view|add_to_cart", "product_id":"..." }`.
- `POST /api.php?action=order`: JSON `{ "key":"SLUG", "session_id":"...", "name":"...", "phone":"...", "address":"...", "note":"...", "items":[{"product_id":"...","quantity":1}] }`.

Web sayfası bu uçları aynı domainde kullanır. Aktif ziyaretçi sayısı 20 saniyede bir yenilenir; WebSocket veya ayrı servis gerekmez. Sipariş sonrası müşteri WhatsApp bağlantısını açabilir. Sipariş doğrudan uygulamanızın mevcut `orders` tablosuna yazılır; uygulama bu tabloyu yenilediğinde siparişi görür. Firebase push bildirimi bu pakete dahil değildir; mevcut uygulamanızın API/push kodu paylaşılmadığı için güvenli biçimde bağlanamaz.

Canlıya almadan önce hostingdeki gerçek tablo yapısı ve PHP sürümüyle entegrasyon yapılmalıdır. DDL'de kullanıcı oturumlarını doğrulayacak bearer token tablosu/servisi bulunmadığından bu katalog linki herkese açık katalog varsayar. Sipariş endpoint'i spam koruması olmadan kullanılmamalı; KVKK bilgilendirmesi, saklama süresi ve rate limit eklenmelidir. `config.local.php` hiçbir durumda web kökünden erişilebilir olmamalıdır.
